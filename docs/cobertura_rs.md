# Cobertura RS ampliada

194 sedes no rodízio editorial de 12 grupos, seis por Reel. O cadastro de apoio completa 497 municípios. A consulta de apoio intercala até 48 municípios por execução com as sedes editoriais, respeitando o limite de tempo do coletor. Cobertura real é registrada no destaque de chuva; cadastro não significa previsão disponível. A MET Norway permanece como fonte; não habilitamos a API gratuita do Open-Meteo para uso comercial. As 25 bacias SEMA são referência cadastral, não confirmação de monitoramento hidrológico individual. Alertas oficiais permanecem sujeitos às travas existentes. A previsão noturna e a manhã seguinte cobrem grupos distintos para a mesma data. Grupos fixos por turno garantem também cobertura complementar no dia de publicação.
